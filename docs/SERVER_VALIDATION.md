# 服务器增量验收记录

日期：2026-10-24（Asia/Shanghai）。

## 已实测

- 合并后端与服务器适配器测试：30 passed, 1 skipped，20.52 秒。
- 测试覆盖：HTTP 鉴权、输入格式、现有本地后端协议兼容、生成失败后的修复、关闭修复的基线、最多两次修复、澄清请求不产生虚假实体、错误信息脱敏、代码过滤、Docker 命令限制、无容器时拒绝启动。
- 实际使用 CadQuery 创建 STEP，并通过现有本地后端重新导入，生成 STL 和几何报告。
- 几何指标测试：相同实体 IoU=1；80×60×12 与 80×60×15 的同坐标系 IoU=0.8，最大包围盒尺寸误差=3 mm。
- 评估请求检查：没有将 ground-truth STEP、标签参数或源码传给模型。
- 训练数据导出检查：仅接受人工审核训练标签；拒绝同 group 跨训练/测试泄漏。
- datasets/smoke32 含32项，图纸哈希、STEP 文件头、参数与真实包围盒及几何检查逐一核对。全部属于同一模板家族，全部为 test，不用于真实模型准确率声明。
- drawing2cad-server-source.zip 已生成，包含服务器、后端源码及接口说明，不包含 server.env、.env、密钥、虚拟环境、模型权重或任务数据。
- 文件数量和 SHA256 记录见 server-delivery.json。
