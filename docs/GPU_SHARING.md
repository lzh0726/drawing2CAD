# 在线推理 GPU 共享规则

仅在线按需推理启用共享。训练和离线评估的空闲卡检查保持原状。

1. 优先完全空闲卡：连续两次、至少间隔 1 秒，无计算进程，显存使用小于 256 MiB，利用率为 0，空闲显存不少于 36 GiB。
2. 其次共享卡：每 2 秒采样，连续 6 次且跨度至少 10 秒；每次利用率不超过 20%，空闲显存不少于 36 GiB；窗口内空闲显存波动不超过 512 MiB，计算进程 PID 集合不变。
3. 同类候选优先剩余显存最多的卡，再比较利用率。功率不参与准入。
4. 共享模式在模型加载之前设置 PyTorch allocator 28 GiB 上限。它不覆盖所有 CUDA/第三方分配，不是硬件显存配额；尚未进行 16384 token 完整输出的 GPU 峰值测试。
5. 共享推理每 5 秒检查剩余显存；低于 6 GiB或监控失败则退出本项目推理进程。只终止本项目子进程，不干预其他任务。
6. 保留项目文件锁和单请求执行、5 分钟排队、180 秒生成及 240 秒加载/推理总限时。取消、异常和结束均清理子进程。
7. GPU 查询失败或指标不可解析时不启动任务。历史样本只在当前请求内保留。

阈值为保守起始配置，不保证没有干扰。其他用户可以在准入之后增加负载或显存，监控也存在采样间隔。严格资源隔离仍需管理员调度。共享启用后，页面显示“空闲或满足共享条件”，不再承诺不与已有任务共用显卡。

本次部署只运行 CPU 自动测试和 nvidia-smi 只读采样，不启动 GPU 推理、不改变既有评估结果。
