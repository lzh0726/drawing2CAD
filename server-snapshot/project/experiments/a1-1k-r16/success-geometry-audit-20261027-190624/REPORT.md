# 成功实体的尺寸、拓扑及低 IoU 审计

## 结论

成功生成的 34 个 STEP 均通过重新导入后的单实体、几何有效性和壳闭合检查，但不能据此称为正确还原。13/34 的固定 XYZ 外包尺寸相对误差不超过 1%，16/34 不超过 5%；忽略轴顺序后分别为 19/34 和 23/34。15/34 的体积误差不超过 5%。因此既有坐标方向差异，也有真实尺寸和内部结构错误。

边界网格的拓扑亏格可比较 33 个，发现 5 个与标准模型不同；另 1 个参考 STEP 的离散网格出现非流形边，暂不对它的拓扑一致性下结论。亏格一致仅说明未发现这类贯通通道差异，不能保证凹槽、盲孔、孔位、轮廓和所有拓扑细节一致。

## 0.415 的准确含义

0.414977 是**此前评估**中，44 个有效标准样本的“包围盒中心平移对齐 IoU 均值”，10 个失败样本记 0。本轮实体率评估没有重算全体 IoU。

| 口径 | 原坐标 IoU | 仅包围盒中心平移后的 IoU |
|---|---:|---:|
| 全部 44 个，失败记 0 | 0.233060 | 0.414977 |
| 仅 34 个成功实体 | 0.301607 | 0.537029 |

两者关系为 `0.537029 × 34/44 = 0.414977`。IoU 是两实体交集体积除以并集体积，不是“尺寸正确率”。

本次核实 34 个成功样本的新首答均与此前原始回答逐字相同，并重新审计了新 STEP；为避免误导，表中的旧 IoU 保留来源标注，不冒充对新 STEP 重算得到的全体成绩。

原对齐只移动包围盒中心，不旋转、不缩放，也不保证平移到最优重叠位置。某些样本的 XYZ 厚度方向不一致，单纯平移后依然重叠很小。原坐标与平移指标都应保留，用刚体对齐诊断补充解释，不能事后换口径只报更高分数。

## 代表性问题

### 00141107：外尺寸完全相同，却把空心方管生成成实心长方体

预测和标准外包尺寸均为 `0.375 × 0.375 × 0.75`。原图顶视图明确有内外两个方框。标准模型有贯通内孔、边界亏格为 1，预测为 0；预测体积比标准大约 322.5%。即使外尺寸全部正确，平移后 IoU 也只有 0.236676。

### 00427410：外径和长度正确，内径错误

标准和预测外包尺寸均为 `0.678947 × 0.678947 × 0.75`，拓扑均为单孔圆筒。但标准内半径约 0.297039，预测约 0.276316，内径偏小、壁厚偏大；体积误差约 44.0%，IoU 为 0.694486。该原图只明确标注外包尺寸，没有内径数值，不能仅凭外尺寸认为内部尺寸已被可靠确定。

### 姿态错误会明显压低 IoU，但并非全部低分都能靠对齐解决

对六个“忽略轴顺序后外包尺寸误差不超过 1%，但固定 XYZ 不匹配”的样本补做了刚体诊断：枚举 24 种保持右手性的轴向旋转，排除反射，选择外包尺寸匹配候选；固定种子采样选候选后，再做精确布尔 IoU。只旋转和平移，不做缩放。采样只用于选择候选，下面报告的是实际完成的精确比较。

| 样本 | 此前仅平移 IoU | 本次刚体轴向对齐诊断 IoU |
|---|---:|---:|
| 00070021 | 0.006384 | 1.000000 |
| 00231272 | 0.024810 | 0.999405 |
| 00344795 | 0.056547 | 1.000000 |
| 00753045 | 0.067449 | 1.000000 |
| 00878404 | 0.023975 | 0.565096 |

00070021、00231272、00344795、00753045 主要受姿态影响。00878404 即使纠正姿态仍只有约 0.565：预测成实心平板，标准为带不同厚度和筋条的板件。它的外包尺寸集合相同，但预测体积约多 77%，结构仍不正确。不能仅通过轴顺序交换就认定形状正确。

## 拓扑差异清单

| 样本 | 预测边界亏格 | 标准边界亏格 |
|---|---:|---:|
| 00141107 | 0 | 1 |
| 00241318 | 0 | 2 |
| 00442545 | 0 | 2 |
| 00763349 | 0 | 5 |
| 00812431 | 0 | 1 |

这里的亏格描述闭合边界表面的拓扑通道，不直接等于圆孔数量。面数/边数可能因曲面分割不同而不同，所以没有仅凭面数判定拓扑错误。比较方法为将曲面离散、焊接重复边界顶点，验证每条边恰好关联两个三角形，再按 Euler 示性数推导表面总亏格；盒体和圆环自测分别验证为 0 和 1。网格尺度为最大外包尺寸 / 1000，焊接阈值为最大尺寸 × 1e-8。

00144800 的参考网格存在两条非流形边，未通过此离散拓扑检查。参考 BRep 本身仍有效，因此没有将它判为模型无效或改动评估分母。

## 尺寸判断边界

- 上述 1% / 5% 是本次诊断阈值，不是用户指定的制造公差。
- 外包尺寸正确不代表孔径、孔距、壁厚、倒角和槽深正确。本次同时检查体积、圆柱曲面半径和拓扑，具体原始测量见每例 JSON。
- 标称单位沿用项目当前数据的 mm；部分数据源使用归一化 CAD 尺度。本次是与配对 STEP 和图纸数值比较，不能由此证明恢复了原始工程零件的物理尺寸。
- 原图没有明确标注的尺寸，应提示补充或说明估计；标准标签比较可以暴露差异，但不意味着所有未标参数都能从图纸唯一推断。

## 完成方式与后续方向

全部测量在独立 CPU Bubblewrap 沙箱中完成，没有运行生成的 Python 源码或启动 GPU。原始评估、数据清单和 STEP 的前后哈希一致；线上服务没有修改。

下一步应同时约束坐标约定、孔槽/薄壁等结构特征以及图纸尺寸。评估应并列报告有效实体率、同坐标 IoU、仅平移 IoU，以及单独定义的刚体对齐诊断；不能把有效率当作重建正确率。先在开发集改进这些问题，再用未参与诊断的独立测试集检验。
